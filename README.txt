REPFUEL TRAINER DASHBOARD — GITHUB PAGES

1. Upload index.html to the ROOT of your GitHub repository.
2. Commit it to the main branch.
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Choose branch "main" and folder "/ (root)", then Save.
6. Wait for Pages deployment and open the published URL.

This is a static visual starter with sample data and simple navigation/search.
It is not connected to Supabase yet. Sample clients, numbers, and sessions are fictional.
Do not put private keys in this file. Supabase integration will be added separately.
